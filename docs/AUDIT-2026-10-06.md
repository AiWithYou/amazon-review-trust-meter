# v2.2.1 バグ確認・提出準備記録

確認日: 2026年10月6日（日本時間）。

## 修正

| 再現した問題 | 修正・確認 |
|---|---|
| `10時間` と `10.0時間` などの表記差で仕様矛盾を加点 | 比較値の先頭・末尾の不要なゼロを文字列で除去。大きい整数や精密な小数はNumber変換せず区別し、根拠表示の元の値は保持 |
| 商品詳細表の値を説明として取得しない | `#productDetails_detailBullets_sections1` を分析対象に追加 |
| 表のセル・行や箇条書き・段落を連結して架空の仕様値を作る | DOMの構造境界に区切りを入れ、インラインの数値は結合 |
| 入れ子の説明領域を二度数え、説明内のコードも仕様値として拾う | 内包された選択領域を重複除外。SCRIPT・STYLE・TEMPLATE・NOSCRIPTを除外 |
| 挿入先が後から追加・削除されてもカードの位置が変わらない | 分析値が同じでも挿入位置を確認し、同じカードを移動。詳細の開閉状態を保持 |
| プロフィールURLの属性変更を検出しない | 関連する `href` 更新をMutationObserverの対象に追加し、投稿者重複を再判定 |

追加した回帰ケースは修正前に失敗することを確認しました。過去に未コミットだった仕様比較・DOM抽出の修正と追加テストも今回のリリースへ含めています。

## 検証

- `npm run check`: 構文確認と回帰テスト80件。全件成功。
- `npm audit`: 開発依存を含め、報告された脆弱性0件。
- `npm run benchmark -- v2.2.0`: 本文クラスタ3条件の結果は旧版と完全一致。Node.js 24.14.0で現在の中央値は0.609 / 6.325 / 1.917ms、旧版は0.769 / 6.400 / 1.756ms。今回の修正による速度向上を示す測定ではありません。
- Chromeのローカルプレビュー: 詳細開閉、同文字数の仕様変更で注意度0→18、開いた状態の保持を確認。
- 通常例と仕様矛盾例: 8件のサンプル本文で、注意度0と36、矛盾根拠「連続時間12↔10、電池容量5000↔3000」を確認。
- 1280 × 800、390 × 844の表示を確認。390px幅で文書の横幅390px、カード幅358px、横スクロールなし。
- Playwright同梱Chromium 153の独立したプロファイルへManifest V3拡張として読み込み、ページ側に分析コードを挿入せずに、宣言的content scriptとCSSの動作を確認。
- Amazonドメインへのブラウザ要求をサンプルHTMLへ置き換え、`/dp/`、`/商品名/dp/`、`/gp/product/` の3パターンで一枚だけ表示。検索ページには挿入されないことを確認。
- 拡張のisolated world、注意度0→36の更新、詳細の開閉・Enterキー操作、開いた状態の保持、後から追加・削除された挿入先への移動と復帰を確認。
- サクラチェッカーへのリンクはASIN、`_blank`、`noopener`を確認。クリックによる外部移動は実施していません。
- 検証対象のconsole error/warn、予期しない外部リクエストは0件。

これはサンプルDOMでの検証です。現在のAmazonの全レイアウト、ログイン状態、ページ更新方式を網羅したライブサイト検証や、不正レビューの検出性能の評価は実施していません。
